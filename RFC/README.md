# RFCs

Design records for architecture and schema changes.

1. Copy `0001-template.md` to `NNNN-short-title.md`
2. Open a GitHub Discussion in the **RFCs** category (or a PR)
3. Label related issues `needs-rfc`
4. Merge only after maintainer approval

Breaking changes to `MissionIntent` or catalog schema **require** an RFC while the project is in `0.x`.
